# GreenRidge Bookkeeping Website

GitHub Pages-ready two-page website for GreenRidge Bookkeeping.

## Files
- `index.html` — homepage
- `contact.html` — contact page
- `styles.css` — responsive layout and navigation overlays
- `assets/` — page artwork

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder, keeping the `assets` folder intact.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save.
5. GitHub will provide the live site URL.
